# Triage Labels

## State Roles

| Role | GitHub label | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Requires maintainer evaluation |
| needs-info | needs-info | Waiting for additional information |
| ready-for-agent | ready-for-agent | Fully specified for agent implementation |
| ready-for-human | ready-for-human | Requires human action |
| wontfix | wontfix | Will not be actioned |

## Category Roles

- `bug`: existing behavior is broken.
- `enhancement`: new functionality or improvement.

Each triaged issue carries exactly one category and one state.
Replace the previous state label when transitioning.

Tickets produced by `/to-tickets` are already agent-ready;
they do not need another triage pass.
